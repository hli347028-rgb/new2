# AIX 联调 / 局域网访问

本机服务已监听 `0.0.0.0`，同一 Wi‑Fi / 同一 Radmin VPN 下的同事可用下列地址访问。

## 推荐地址（同一 Wi‑Fi）

本机 WLAN：`192.168.3.6`

| 端 | 地址 |
|---|---|
| 用户端 H5 | http://192.168.3.6:9200/ |
| 管理后台 | http://192.168.3.6:9300/admin/ |
| API（一般不必直连） | http://192.168.3.6:9000/ |

若浏览器打不开，先确认本机「专用网络」防火墙是否放行 **9000 / 9200 / 9300**（需管理员权限添加入站规则）。

## Radmin VPN（不在同一 Wi‑Fi 时）

| 端 | 地址 |
|---|---|
| 用户端 H5 | http://26.3.54.166:9200/ |
| 管理后台 | http://26.3.54.166:9300/admin/ |

## 账号说明

- **用户端**：需 MetaMask（BSC），首次登录要填邀请码（已注册用户的钱包地址；可用零地址若已作引导账号）。
- **管理后台**：`admin` / `admin123`

## 本机启动（若服务挂了）

```bash
# 后端
cd c:\Users\86186\Desktop\new2
.\bin\server.exe -conf ./configs

# 用户端
cd web
npm run dev

# 管理端
cd admin
npm run serve
```

用户端通过 Vite 代理访问 `/v1` → 本机 `9000`，他人打开 H5 的 Network 地址即可，无需单独配 API 域名。
