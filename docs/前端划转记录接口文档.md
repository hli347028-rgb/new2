# 前端划转记录接口文档

> 状态：接口已实现并注册，前端可直接调用。数据来自数据库 `transfers` 表。

## 1. 通用约定

- 局域网基础地址：`http://192.168.3.6:8081`
- Radmin VPN 基础地址：`http://26.3.54.166:8081`
- 前后端同域时使用相对路径。
- 请求必须携带登录令牌：

```http
Authorization: Bearer <token>
```

- 时间统一返回 Unix 秒时间戳，字段名为 `created_at`。
- 金额统一返回十进制字符串，前端不要使用 JavaScript 浮点数直接计算。
- 默认按创建时间倒序排列，最新记录在前。

## 2. 用户本人钱包划转记录

查询当前用户从“充值钱包”划转到本人“奖励钱包”的记录。

### 接口

```http
GET /v1/wallet/transfer-records/self?page=1&page_size=10
```

### 查询参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | number | 否 | `1` | 页码，从 1 开始 |
| `page_size` | number | 否 | `10` | 每页数量，建议最大 100 |

### 筛选规则

后端应只返回同时满足以下条件的记录：

- `from_user_id` 等于当前登录用户 ID；
- `to_user_id` 等于当前登录用户 ID；
- `pay_from` 等于 `recharge`；
- `remark` 等于 `recharge_to_reward`。

### 成功响应

HTTP 状态码：`200`

```json
{
  "page": 1,
  "page_size": 10,
  "total": 2,
  "list": [
    {
      "id": 201,
      "asset": "USDT",
      "amount": "50",
      "from_wallet": "recharge",
      "to_wallet": "reward",
      "created_at": 1786411663
    }
  ]
}
```

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `page` | number | 当前页码 |
| `page_size` | number | 每页数量 |
| `total` | number | 符合条件的总记录数 |
| `list` | array | 当前页记录 |
| `list[].id` | number | 划转记录 ID |
| `list[].asset` | string | 固定为 `USDT` |
| `list[].amount` | string | 划转金额 |
| `list[].from_wallet` | string | 固定为 `recharge` |
| `list[].to_wallet` | string | 固定为 `reward` |
| `list[].created_at` | number | 创建时间，Unix 秒 |

## 3. 上下级用户之间划转记录

查询当前用户与邀请树直系上下级之间的奖励钱包 USDT 划转记录，包括转入和转出。

### 接口

```http
GET /v1/wallet/transfer-records/lineal?page=1&page_size=10&direction=all
```

### 查询参数

| 字段 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `page` | number | 否 | `1` | 页码，从 1 开始 |
| `page_size` | number | 否 | `10` | 每页数量，建议最大 100 |
| `direction` | string | 否 | `all` | `all`、`in` 或 `out` |

### 筛选规则

- 当前用户是 `from_user_id` 或 `to_user_id`；
- `from_user_id` 与 `to_user_id` 不相等；
- `pay_from` 等于 `reward`；
- `asset` 等于 `USDT`。

### 成功响应

HTTP 状态码：`200`

```json
{
  "page": 1,
  "page_size": 10,
  "total": 3,
  "list": [
    {
      "id": 305,
      "direction": "out",
      "relationship": "downline",
      "counterparty_user_id": 11,
      "counterparty_address": "0x9e3730f324476c15b9cf1b1991e0c2cc5c8d1575",
      "asset": "USDT",
      "amount": "100",
      "from_wallet": "reward",
      "to_wallet": "reward",
      "created_at": 1786411663
    },
    {
      "id": 304,
      "direction": "in",
      "relationship": "upline",
      "counterparty_user_id": 8,
      "counterparty_address": "0xb8726f15099956183c3a0431791458a096404ca6",
      "asset": "USDT",
      "amount": "20",
      "from_wallet": "reward",
      "to_wallet": "reward",
      "created_at": 1786411000
    }
  ]
}
```

### 响应字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `direction` | string | 相对当前用户的方向：`in` 转入、`out` 转出 |
| `relationship` | string | 对方相对当前用户的关系：`upline` 上级、`downline` 下级 |
| `counterparty_user_id` | number | 对方用户 ID |
| `counterparty_address` | string | 对方钱包地址 |
| `asset` | string | 固定为 `USDT` |
| `amount` | string | 划转金额，始终返回正数 |
| `from_wallet` | string | 固定为 `reward` |
| `to_wallet` | string | 固定为 `reward` |
| `created_at` | number | 创建时间，Unix 秒 |

`direction` 和金额展示建议：

- `out`：前端显示 `-100 USDT`；
- `in`：前端显示 `+100 USDT`。

## 4. TypeScript 类型定义

```ts
export interface PageResult<T> {
  page: number
  page_size: number
  total: number
  list: T[]
}

export interface SelfTransferRecord {
  id: number
  asset: 'USDT'
  amount: string
  from_wallet: 'recharge'
  to_wallet: 'reward'
  created_at: number
}

export type TransferDirection = 'all' | 'in' | 'out'

export interface LinealTransferRecord {
  id: number
  direction: Exclude<TransferDirection, 'all'>
  relationship: 'upline' | 'downline'
  counterparty_user_id: number
  counterparty_address: string
  asset: 'USDT'
  amount: string
  from_wallet: 'reward'
  to_wallet: 'reward'
  created_at: number
}
```

## 5. Axios 调用示例

```ts
import axios from 'axios'

function authHeaders(token: string) {
  return { Authorization: `Bearer ${token}` }
}

export async function getSelfTransferRecords(
  token: string,
  page = 1,
  pageSize = 10,
): Promise<PageResult<SelfTransferRecord>> {
  const { data } = await axios.get<PageResult<SelfTransferRecord>>(
    '/v1/wallet/transfer-records/self',
    {
      params: { page, page_size: pageSize },
      headers: authHeaders(token),
    },
  )
  return data
}

export async function getLinealTransferRecords(
  token: string,
  direction: TransferDirection = 'all',
  page = 1,
  pageSize = 10,
): Promise<PageResult<LinealTransferRecord>> {
  const { data } = await axios.get<PageResult<LinealTransferRecord>>(
    '/v1/wallet/transfer-records/lineal',
    {
      params: { direction, page, page_size: pageSize },
      headers: authHeaders(token),
    },
  )
  return data
}
```

## 6. 时间格式化

```ts
export function formatUnixTime(timestamp: number): string {
  if (!timestamp) return '-'
  return new Date(timestamp * 1000).toLocaleString('zh-CN', {
    hour12: false,
  })
}
```

## 7. 错误响应

```json
{
  "code": 401,
  "reason": "UNAUTHORIZED",
  "message": "请先登录"
}
```

| HTTP 状态 | `reason` | 说明 |
| --- | --- | --- |
| 400 | `INVALID_PAGE` | 页码或每页数量无效 |
| 400 | `INVALID_DIRECTION` | `direction` 不是 `all`、`in` 或 `out` |
| 401 | `UNAUTHORIZED` | 未登录或令牌失效 |
| 500 | `INTERNAL_ERROR` | 查询记录失败 |

## 8. 与现有数据库字段的对应关系

| 前端字段/记录类型 | 数据库判断或来源 |
| --- | --- |
| 本人钱包划转 | `from_user_id = to_user_id = 当前用户ID` |
| 本人钱包划转来源 | `pay_from = recharge` |
| 本人钱包划转标记 | `remark = recharge_to_reward` |
| 上下级互转 | `from_user_id != to_user_id` 且当前用户为其中一方 |
| 上下级互转来源 | `pay_from = reward` |
| `direction = out` | `from_user_id = 当前用户ID` |
| `direction = in` | `to_user_id = 当前用户ID` |
| `amount` | `transfers.amount` |
| `created_at` | `transfers.created_time` 转为 Unix 秒 |
| `counterparty_address` | 关联 `users` 表取得对方地址 |
